
# Challenge Intelliway

## Sobre o projeto

O Challenge Intelliway é um projeto acadêmico desenvolvido no curso de Inteligência Artificial da FIAP.

A proposta inicial é estudar e desenvolver uma solução para identificar possíveis ataques de prompt injection em textos em português brasileiro (PT-BR).

## Objetivo

Investigar técnicas de detecção de instruções maliciosas que possam tentar manipular o comportamento de sistemas de inteligência artificial.

## Escopo inicial

- Estudo do problema de prompt injection.
- Pesquisa de técnicas de classificação de texto.
- Planejamento de uma base de exemplos em português brasileiro.
- Definição de uma API para análise e classificação de entradas.
- Planejamento de um portal administrativo.
- Avaliação de métricas de desempenho e segurança.

## Tecnologias

As tecnologias serão definidas durante o planejamento técnico, considerando os requisitos oficiais do projeto.
